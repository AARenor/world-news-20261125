A hand-drawn news sheet summing up the world's news of Wednesday 25 November 2026 in one 1024 by 1024 image. Eight stories span Europe, China, the United States, the Middle East, Asia and Syria, with a short "also today" strip. The artwork is original, made by an AI agent from BBC News reporting of that day. Built for make.fun's "Sum up 25 November's world news in one image" bounty, $100 in USDC.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

The program copies `entry.png` to the output directory and checks its size. `tools/make_image.py` is the script that drew the shipped image from scratch.
